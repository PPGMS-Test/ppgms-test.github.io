PayPal Integration Demo

SPB (JSv5) w/ Apple Pay

用 paypal.Buttons() 的 Smart Payment Buttons 方式渲染 Apple Pay（BCDC 场景）—— Apple Pay 作为按钮栈中的一颗，由 SDK 内部托管 ApplePaySession。后台不走服务器代理，直接在前端用 client credentials 调 PayPal REST API 建单 / 捕获。

凭据配置（沙箱默认已填，可改）

改动金额 / 币种 / 凭据后，点击 “Render SPB” 会用最新参数重新加载 SDK 并渲染按钮。

点击上方 “Render SPB” 渲染支付按钮
