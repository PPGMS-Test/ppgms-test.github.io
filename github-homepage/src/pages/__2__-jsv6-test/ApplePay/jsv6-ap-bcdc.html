JSv6 Apple Pay through BCDC

  • SDK 只支持 Web SDK v6;JSv5(Smart Payment Buttons)不支持。
  • Merchant US 主体的商户无法开通此集成。
  • Session 走 createBasicApplePayOneTimePaymentSession(),一个简化版 Apple Pay(基础一次性付款)。
  • Domain 无需 Apple 域名注册——域名验证由 PayPal 统一托管。
  • Region 文案与 UI 因地区而异(例如 EU 与 3PL 存在差异)。
  • Button 按钮需自行绘制,或按 Apple 官方最佳实践(有一份 CSS 指引)实现。
